# 🚀 نظام لينوكور (Lenokor OS) - الإصدار Lenokor 900

**نظام لينوكور (Lenokor OS)** هو نظام تشغيل مبتكر ومستقل، بدأ تطويره في عام **2023** وجرى إطلاقه رسمياً في عام **2026**. أثار النظام اهتماماً واسعاً ونقاشاً في الأوساط التقنية ومجتمعات المطورين بسبب بنيته البرمجية الهجينة وغير التقليدية، والتي تجمع بين لغات البرمجة منخفضة المستوى وعالية المستوى وتقنيات تطوير الويب.

---

## 🛠️ البنية التحتية واللغات البرمجية

يمتلك نظام **Lenokor** ميزة استثنائية؛ فهو **نظام خفيف وسريع للغاية** صُمم ليدعم **جميع أنواع أجهزة الكمبيوتر**، سواء كانت أجهزة حديثة بمواصفات قوية أو أجهزة قديمة ومحدودة الموارد. يعتمد النظام في نواته وإدارته للعمليات على توليفة هجينة وفريدة:

| الجزء البرمجي | لغات البرمجة المستخدمة |
| :--- | :--- |
| **إدارة العتاد والنواة** | `Assembly` (لغة التجميع) لضمان التحدث المباشر مع المعالج وأقصى سرعة ممكنة. |
| **العمليات الأساسية والنظام** | `C#` (سي شارب) و `Kotlin` (كوتلن) لبناء بيئة توافقية مرنة وإدارة المهام. |
| **واجهة المستخدم المتطورة** | `HTML` و `CSS` لبناء الهيكل البصري والتصميم الجمالي. |
| **إدارة البيانات الخلفية** | `PHP` لمعالجة البيانات والعمليات المرتبطة بالواجهة. |

## 🖥️ واجهة المستخدم (UI)
يحتوي النظام على واجهة مستخدم قوية ومتطورة بصرياً، تعتمد بالكامل على تقنيات الويب الحديثة، مما يوفر سلاسة تامة وسهولة في التنقل دون استهلاك موارد الجهاز.

## 📜 شروط الاستخدام والاتفاقيات

1. **الاستخدام الشخصي:** يُسمح باستخدام النظام بالكامل للأغراض الشخصية فقط.
2. **النسخ الاحتياطي:** يجب على المستخدم التأكد من أخذ نسخة احتياطية من ملفاته المهمة قبل تثبيت النظام.
3. **الملكية الفكرية:** جميع حقوق اسم لينوكور محفوظة للمطور، ويمنع تماماً إعادة بيع ملفات النظام أو تقديمها تحت اسم جهة أخرى دون إذن مسبق.
4. **المسؤولية:** المستخدم مسؤول عن طريقة التثبيت وأي تعديلات يجريها على جهازه، ولا يتحمل المطور مسؤولية أي فقدان للبيانات نتيجة سوء الاستخدام.
